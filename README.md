Overview

Community Resource Finder is a Python project that helps users locate food assistance and community support resources by searching with a ZIP code, organization name, or resource type.

The goal of this project is to make it easier for individuals and families to identify available support services within their community.

Why I Built This

I created this project to help people quickly find local resources such as food pantries, meal programs, and community support organizations. This project connects to my interest in using technology to solve real-world problems and support communities.

Features
Search by ZIP code
Search by resource type
Search by organization name
View addresses, phone numbers, and hours
Continue searching without restarting the program
Simple and beginner-friendly interface

How to Run
Download the project files.
Make sure both community_resource_finder.py and resources.csv are in the same folder.
Run the Python file:
python community_resource_finder.py
Enter a ZIP code, resource type, or organization name when prompted.
