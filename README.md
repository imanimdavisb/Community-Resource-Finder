# Community Resource Finder

Community Resource Finder is a Python project that helps users find food assistance and community support resources by searching for a ZIP code, organization name, or resource type.

## Why I Built This

I created this project to help people quickly find local resources such as food pantries, meal programs, and community support organizations. This project connects to my interest in using technology to solve real-world problems and support communities.

## Features

- Search by ZIP code
- Search by resource type
- Search by organization name
- View addresses, phone numbers, and hours
- Continue searching without restarting the program

## Technologies Used

- Python
- CSV files
- User input
- Data filtering

## How to Run

1. Download the project files.
2. Make sure `community_resource_finder.py` and `resources.csv` are in the same folder.
3. Run the Python file:

python community_resource_finder.py
